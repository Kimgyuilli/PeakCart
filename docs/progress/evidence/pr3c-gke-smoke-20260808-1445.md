## 배포 편차 (증적 정직성)

본 게이트는 신규 GCP 프로젝트(`peekcart-gate`, 조직 하위)에서 1회성으로 수행했으며 다음은 계약과 다르다:

1. **노드 SA IAM**: 조직 정책으로 기본 컴퓨트 SA 자동 부여가 꺼져 있어 AR pull 이 403 → `roles/artifactregistry.reader` 수동 부여. loadgen VM 의 `clusters describe`/`kubectl` 용으로 `roles/container.developer` 추가 부여.
2. **user-service RS256 개인키**: ADR-0013 D2 는 Secret Manager + CSI 파일 마운트를 규정하나, 본 게이트는 **k8s Secret(`user-jwt-private`) 마운트**로 대체했다. 게이트 검증 대상(NetworkPolicy·직접경로)과 무관한 부팅 전제라 판단. **PR3d P5 의 CSI 마운트 계약은 본 증적으로 충족되지 않는다.**
3. **자격증명**: `SLACK_WEBHOOK_URL`·`TOSS_SECRET_KEY`·`TOSS_WEBHOOK_SECRET` 은 `docker-health-smoke.sh` 의 placeholder 값을 런타임 주입(실제 자격증명 아님). 외부 연동은 미검증.
4. **스크립트 결함**: 증적 헤더 `- canary:` 가 `n/a` 로 남는다 — `CANARY_RESULT` 가 `tee` 파이프라인 서브셸에서 설정돼 부모 셸로 전파되지 않음. 실제 canary 결과는 로그 블록에 보존됨. PR3d 에서 수정 대상.
